# Japanese_book_review_template
ChatGPT等の対話型AIを活用し、中高生の読書感想文をステップバイステップで作成・推敲するための汎用テンプレートです。エディタや各種AIツールのProject機能に読み込むだけで、誰でも簡単にシステマチックな文章作成ワークフローを構築できます。【主な機能】構成の組み立てから清書までを案内するステップ式プロンプト読書中の気づきを引き出す、本専用の「読書質問リスト」生成感想文の世界観をビジュアル化する「挿絵用の画像生成プロンプト」読書感想文の「何を書けばいいかわからない」をAIとの対話で解決し、論理的で豊かな表現力をもつ原稿の完成をサポートします。
